# C++17 snippets for competitive programming

18 сниппетов для VS Code: шаблоны решения, ввод-вывод, алгоритмы и структуры данных.
Набор подготовлен с помощью ИИ.

## Установка

1. Скачитайте [cp.code-snippets](cp.code-snippets).
2. Скопируйте его в папку `.vscode` своего проекта.
3. Откройте папку проекта в VS Code.
4. В файле `.cpp` введите префикс и выберите сниппет через **Ctrl+Space → Enter**.
   Для раскрытия по **Tab** включите `"editor.tabCompletion": "onlySnippets"`.

Перемещайтесь между полями через **Tab / Shift+Tab**.
Команда **Insert Snippet** также доступна в палитре **Ctrl+Shift+P**.

## Условия применения

- `cp` и `cp1` вставляйте в пустой файл.
- Структуры и функции (`dsu`, `fenwick`, `segsum`, `bfs`, `dijkstra`,
  `modpow`, `sieve`, `pifunc`) вставляйте вне `main()` / `solve()`,
  после заголовков и `using namespace std;`. Остальные сниппеты вставляйте внутри функции.
- Нужен GCC с C++17 и `<bits/stdc++.h>` либо соответствующие стандартные заголовки.
- Индексы начинаются с 0. Для запросов сумм отрезок **[l, r)** включает l и не включает r.
  Индексы и границы должны быть допустимыми.
- Для BFS и Дейкстры начальная вершина должна существовать.
- Для Дейкстры веса неотрицательные, расстояния строго меньше `LLONG_MAX / 4`;
  это значение обозначает недостижимую вершину.
- Для `modpow`: степень >= 0, модуль от 1 до 2 000 000 000.
- `bsfirst` требует заданного `n < INT_MAX` и монотонного предиката `good(i)`
  с переходом false → true; ответ `r = n` означает, что подходящего индекса нет.
- Суммы должны помещаться в `long long`.

## Использование на соревнованиях

Перед использованием проверьте правила конкретного соревнования.

[Пункт 15 правил Codeforces](https://codeforces.com/blog/entry/456?locale=ru)
допускает сторонний код, написанный и опубликованный/распространённый до начала раунда.
Изменения во время раунда нужно вносить самостоятельно. При споре участник должен
доказать соблюдение правил, включая время публикации.
Сохраняйте ссылку на конкретный коммит используемой версии. Публичная история помогает
подтвердить публикацию, но не гарантирует решения организаторов: правило отдельно
упоминает наличие опубликованной версии в кэше поисковых систем.

[Правила использования ИИ на Codeforces](https://codeforces.com/blog/entry/133941?locale=en&mobile=false)
запрещают во время раунда получать от ИИ алгоритмическую логику решения и исправления
по вердиктам тестирующей системы. Публикация набора не отменяет эти ограничения.
